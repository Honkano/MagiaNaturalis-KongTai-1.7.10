**"One must know Death in order to understand the Meaning of Life"**

This is a continuation branch of **Magia Naturalis**.
This is an ancient legacy addon (2014-2015) for Thaumcraft 4, originally released by **Elenterius (formerly TrinaryBrain)** on the Minecraft Forums.

As the original project is no longer maintained, **it is now being jointly maintained and updated by KongTai and AI**. This branch will not only receive bug fixes; **I will continue to add significant gameplay updates and new content** to revitalize this legacy mod.

### ⚠️ Important Compatibility Warning
**If you wish to use "Thaumic Bases" alongside this mod, you MUST use the GTNH (GregTech: New Horizons) maintained version!**

*   **Why?** The GTNH version of Thaumic Bases removed the **"Scythe Of The White-Eyed One"**. However, this fork has added it back for a complete experience.
*   **Legacy (Non-GTNH) Conflict Warning**: If you install this mod alongside the **legacy (non-GTNH)** version of Thaumic Bases, you will see **two different sickles** in-game because the legacy version already contains its own sickle. This causes item conflicts and confusion.
*   **Conclusion**: Please make sure to pair this mod with the **GTNH version** of Thaumic Bases to avoid any conflicts!

### ✨ KongTai's Additions
*   **"Scythe Of The White-Eyed One" Return**: Re-added the "Scythe Of The White-Eyed One" that was removed in the GTNH version.
*   **Sickle Series Enhancement**: Added custom effects, damage upgrades, and new sound effects to the sickle series, making harvesting more immersive.
